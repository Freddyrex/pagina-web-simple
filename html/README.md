# Versión: HTML puro (Web 1.0)

Esta carpeta contiene la **versión original** del sitio web académico de **Freddy Valenzuela**, construida **únicamente con HTML puro** (sin CSS ni JavaScript).

## ¿Qué se implementó?

- Presentación mediante atributos clásicos de HTML: `bgcolor`, `text`, `link`, `vlink`, `alink`.
- Texto con estilos heredados de la Web 1.0 usando etiquetas `<font>` y colores por atributos.
- Navegación basada en tablas (`<table>`, `<td>`, `cellpadding`, `bordercolor`).
- Separadores visuales mediante líneas horizontales `<hr>` con color.
- Imágenes con atributos de tamaño (`width`, `height`).

## Páginas

| Página | Descripción |
|---|---|
| `index.html` | Inicio: sobre mí, mi universidad e intereses académicos |
| `courses.html` | Materias del semestre actual |
| `schedule.html` | Horario semanal de clases |
| `hobbies.html` | Pasatiempos |
| `clubs.html` | Clubes estudiantiles |
| `projects.html` | Proyectos académicos y personales |
| `contact.html` | Formulario de contacto |

## Uso local

No requiere dependencias ni servidor. Solo abre `index.html` en tu navegador.
