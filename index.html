Portafolio académico de Ciencias de la Computación · Universidad Yachay Tech. Este índice agrupa las dos versiones del sitio: la original en HTML puro y el rediseño moderno con CSS.

Selecciona una versión

El proyecto se organiza en dos carpetas. Cada una contiene una implementación distinta del mismo contenido, como se describe a continuación.

Versión original

Carpeta html/

Sitio construido únicamente con HTML puro (estética Web 1.0): atributos presentacionales, etiquetas <font> y tablas para la presentación, sin CSS.

  • Navegación y estilo mediante atributos clásicos
  • 7 páginas enlazadas entre sí
  • Sin JavaScript ni hojas de estilos

Versión moderna

Carpeta css/

Rediseño con HTML semántico + CSS bajo la estética Tech Dark & Clean Minimal: header sticky full-width, tarjetas, iconos SVG y diseño responsivo.

  • Header y footer a ancho completo
  • Sistema de diseño con tokens CSS
  • Diseño responsivo y moderno
